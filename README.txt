OIL MANAGEMENT NOVA 1.0 — ЧИСТАЯ СБОРКА
======================================
Содержимое папки загрузить в корень репозитория GitHub Pages.
index.html, app.js, engine.js, style.css, manifest.webmanifest, изображения.

ВАЖНО:
1. Это новый движок с новым форматом сохранения. Старые Alpha/Rebuild сохранения автоматически НЕ импортируются. Старую игру предварительно сохраните отдельно.
2. Игра работает автономно, без сервера. Автосохранение — после действий и пропуска дней.
3. Сохранения браузера можно экспортировать/импортировать через Настройки (JSON).
4. Продажа нефти разрешена только по действующему договору, отгрузка списывает фактический объём из РВС.
5. Строительство: 25% аванс, 75% при сдаче. При недостатке денег сдача откладывается.
6. Финансовый журнал показывает все движения денег. Капитальные вложения, депозиты, акции и тело кредита не записываются как операционная прибыль/убыток.
7. Численность работников и ФОТ рассчитываются по одному реестру.
8. Автозакупка и авторемонт выключены на старте. Включаются в разделе «Склад».

ПРОВЕРКА:
- node --check engine.js && node --check app.js
- node test.js (локальный тест движка, Node.js 18+)
Браузерный E2E-тест в данной среде не выполнен: браузер блокирует локальные URL.

Известные ограничения: упрощённая модель ценообразования, кадрового подбора и ремонта; нет имитации индивидуальных имён работников, сложных тендеров, ДТП/НС и технологических аварий; не реализована миграция старых сохранений.
